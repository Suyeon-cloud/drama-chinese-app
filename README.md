# 《追剧学汉语》 — 드라마로 배우는 중국어와 문화

중국 드라마의 실제 장면과 대사를 활용해 중국어와 한중 문화를 함께 배우는 **학습 웹앱**입니다.
대학 오프라인 수업의 한 학기(15주) 운영을 고려해, 교수자는 주차별 강의자료를 만들고 학습 현황을 확인하며,
학습자는 영상·자막·병음·학습 콘텐츠를 한 화면에서 학습하도록 구성했습니다.

## 1. 프로젝트 소개

| 항목 | 내용 |
|---|---|
| 프로젝트명 | 《追剧学汉语》 (drama-chinese-app) |
| 성격 | 중국 드라마를 활용한 중국어·문화 학습 웹앱 |
| 대상 | 대학 오프라인 수업의 교수자와 학습자 |
| 수업 구조 | 한 학기 15주 — 1~8주차 **중국어 → 한국어**, 9~15주차 **한국어 → 중국어** |
| 기술 | React · TypeScript · Vite (웹앱), Node.js + Express (서버·API), Remotion (학습 모션그래픽), Google Identity Services, Gmail API |
| 배포 | GitHub 저장소 → Railway (서버 1개 + Volume) |

15주차 강의자료 틀이 모두 들어 있습니다. 1주차는 《以家人之名》 第3集 영상(학습 구간 02:00~10:26) 강의로 공개되어 있고,
2~15주차는 주제별 초안(학습용 대사 · 핵심 표현 · 어휘/문법 · 문화렌즈 · 복습 퀴즈)으로 **‘준비 중’ 상태**입니다.
교수자가 영상을 고른 뒤 ‘강의자료 만들기’에서 YouTube 주소를 연결하고 대사·표현을 영상에 맞게 고쳐 ‘공개’하면 학습자에게 보입니다.

## 2. 주요 기능

### 공통
- **로그인 두 가지**
  - **학습자**: Google 로그인 → 처음이면 팝업에 **성명 · 대학 · 학과 · 학년 · 학번 · 이메일 · 휴대폰 번호** 입력 → **관리자 승인 대기**. 승인 전에는 화면 전체가 막혀 아무것도 누를 수 없고, 승인되면 자동으로 풀립니다.
  - **관리자**: 오른쪽 위 Google 로그인 왼쪽의 **‘관리자’ 아이콘** → 아이디·비밀번호 로그인(Google 계정과 별개). 로그인하면 **회원 현황 팝업**이 바로 열립니다.
- **메뉴(모두 한국어)**
  - 관리자 메뉴: 관리 대시보드 · 수업 관리 · 강의자료 만들기 · 학습자 관리 · 학습 현황 · 피드백 · 교수자 관리
  - 학습자 메뉴: 홈 · 주차·상황 학습(주차별 학습 + 상황별 장면을 한 화면의 탭으로) · 한중문화 · 내 대시보드
- **회원 현황 팝업(관리자)**: 성명 · 대학 · 학과 · 학년 · 이메일 · 휴대폰번호 · 가입일 · 최종접속일 · 회원 승인 · 수정 · 삭제
- **내 대시보드(학습자)**: 회원정보, 완료한 주차 · 평균 진행률 · 퀴즈 정답률 · 연속 학습일, 15주 진도, 주차별 기록, 복습할 표현 (모두 실제 학습 기록으로 계산)

### 교수자
- **15주차 수업 관리**: 주차별 강의자료 목록과 공개 상태(준비 중 / 준비 완료 / 공개)를 관리하고, 학습자에게 보낼 수업 참여 링크·코드를 제공합니다.
- **강의자료 반복 추가·제작**: 개수 제한 없이 새 강의자료를 추가하고 다시 편집할 수 있습니다. 주차를 고르면 학습 방향(중→한 / 한→중)이 기본으로 맞춰지고, 학습 수준(초급·중급·고급)과 그 정의를 함께 확인할 수 있습니다.
- **YouTube URL 기반 영상 확인**: YouTube URL에서 영상 정보(제목·채널·원본 길이)와 원문 언어 자막 트랙(업로더 자막 / 자동 생성 자막) 제공 여부를 확인하고, 가능한 경우 자막을 가져옵니다.
- **음성으로 자막 만들기(무료)**: 자막이 없는 영상은 영상·음성 파일을 올리면 브라우저 안에서 Whisper 음성 인식으로 시간이 맞춰진 원문 자막을 만듭니다. 서버·API 키가 필요 없고 강의자료 수에 제한이 없습니다. 처음 한 번 모델(약 200MB, 정확 모드 약 600MB)을 내려받으며, 결과는 반드시 검수하고 SRT로 저장할 수 있습니다.
- **SRT 업로드 및 원문 직접 입력**: 자막을 가져올 수 없을 때 SRT 파일 업로드·붙여넣기 또는 타임코드 없는 원문을 한 줄에 한 문장씩 입력합니다.
- **학습 구간 설정**: 원본 영상 길이, 학습 구간, 실제 학습 분량을 함께 표시하고 15분 이내 구성을 안내합니다.
- **자막 시간 동기화**: 영상을 재생하며 문장마다 “현재 재생시간 지정”으로 시작 시각을 맞추고, 순서 오류를 알려 줍니다.
- **학습 콘텐츠 구성**: 원문을 바탕으로 핵심 표현 · 어휘/문법 · 문화렌즈 · 복습 퀴즈 초안을 만들고 교수자가 직접 편집합니다. 각 항목은 관련 원문의 동기화 시각에 맞춰 영상 위 등장 시점이 연결되며, 직접 조정할 수 있습니다.
- **원본 영상 자막 가리기**: 영상에 박혀 있는 자막을 가리는 자막 패널의 위치·높이·너비를 실제 영상을 보며 조정합니다.
- **학습 진행상황 확인**: 학습자별 출석(학습 시작), 주차 완료, 영상 재생 정도, 퀴즈 결과를 확인합니다.
- **Gmail 피드백 발송**: 학습 결과를 바탕으로 피드백을 작성·검토한 뒤, 교수자가 버튼을 눌렀을 때만 학습자의 Google 이메일로 Gmail을 보냅니다. 전송 성공(메시지 ID 확인) 시에만 발송 완료와 발송 시각이 기록됩니다.

### 학습자
- **영상 위 자막 및 학습 콘텐츠**: YouTube 영상 위에 원문·병음·번역 자막과, 정해진 시점의 학습 모션그래픽(표현·문법 카드)과 문화렌즈가 나타납니다. 자막·병음은 각각 켜고 끌 수 있습니다.
- **중국어 병음 표시**: 중국어 자막과 스크립트, 핵심 표현·어휘에 성조 부호 병음을 표시합니다. 입력된 병음이 있으면 그것을 쓰고, 없으면 `pinyin-pro`로 자동 변환합니다.
- **한 화면 학습**: 영상 옆 학습 패널에서 스크립트 · 표현 학습 · 문화렌즈 · 퀴즈 탭을 오가며 학습합니다.
- **전체화면 학습**: 영상과 자막·모션그래픽·문화렌즈를 함께 전체화면으로 봅니다.
- **학습 기록**: 실제로 재생한 구간, 진행률, 학습 완료, 퀴즈 결과가 기록되고 ‘나의 학습’에서 확인할 수 있습니다.

## 3. 실행 방법

### 필요 환경
- **Node.js** `20.19` 이상(20.x) 또는 `22.12` 이상 (`package.json`의 `engines` 기준)
- **npm** (Node.js와 함께 설치됨)

### 개발용 실행

```bash
npm install
npm run app
```

브라우저에서 **http://localhost:5173** 으로 접속합니다. 화면과 함께 서버 API(`/api/*`)도 같이 실행되고,
회원·학습 데이터는 프로젝트 폴더의 `data/db.json`에 저장됩니다. (git에는 올라가지 않습니다)

### 배포와 같은 방식으로 실행

```bash
npm run build   # 웹앱(dist-app/) + 서버(dist-server/) 빌드
npm start       # http://localhost:3000
```

### 명령어 구분

| 명령어 | 용도 |
|---|---|
| `npm run app` | **개발용 웹앱 + API 실행** (http://localhost:5173) |
| `npm run build` | 배포용 빌드 (Railway가 자동으로 실행) |
| `npm start` | 배포용 서버 실행 (Railway가 자동으로 실행) |
| `npm run typecheck` | TypeScript 타입 검사 |
| `npm run dev` | ⚠️ 웹앱이 아니라 **Remotion Studio**(학습 모션그래픽 편집 도구) 실행 |
| `npm run remotion:build` | Remotion 번들 (이전의 `npm run build`) |

## 4. 환경변수 설정

로컬에서는 프로젝트 루트에 `.env` 파일을 만들고, Railway에서는 서비스의 **Variables** 탭에 같은 이름으로 넣습니다.
(`.env.example` 참고. 아래는 예시이며 실제 값이 아닙니다.)

```env
GOOGLE_CLIENT_ID=your-client-id.apps.googleusercontent.com   # 구글 로그인 · Gmail 발송
ADMIN_ID=admin                                               # 관리자 로그인 아이디
ADMIN_PASSWORD=긴-비밀번호                                    # 관리자 로그인 비밀번호
DATA_DIR=/data                                               # (Railway) Volume 경로
SESSION_SECRET=아무-긴-임의-문자열                             # (선택) 로그인 쿠키 서명
ADMIN_EMAIL=                                                 # (선택) Gmail 발송 계정
INITIAL_INSTRUCTOR_EMAIL=                                    # (선택) 교수자로 바로 들어갈 Google 이메일
```

- `GOOGLE_CLIENT_ID`는 서버가 화면에 전달하므로, Railway 변수만 바꾸면 다시 빌드하지 않아도 반영됩니다. (이전 이름 `VITE_GOOGLE_CLIENT_ID`도 그대로 읽습니다)
- `ADMIN_PASSWORD`, `SESSION_SECRET`은 비밀 값입니다. 저장소(코드)에 넣지 말고 `.env`/Railway Variables에만 넣으세요.
- `.env`를 수정한 뒤에는 `npm run app`을 다시 실행해야 반영됩니다.

### Google Cloud 설정 안내
자세한 순서는 [docs/배포-가이드.md](docs/배포-가이드.md)의 ‘Google 클라이언트 ID 만들기’를 보세요. 요약하면:

- OAuth 클라이언트(웹 애플리케이션)의 **승인된 JavaScript 원본**에 `http://localhost:5173`과 Railway 주소(`https://○○○.up.railway.app`)를 추가
- Gmail 발송: **Gmail API 사용 설정**, OAuth 동의 화면의 범위에 `https://www.googleapis.com/auth/gmail.send` 추가
- 앱이 ‘테스트’ 게시 상태라면 사용할 Google 계정을 **테스트 사용자**로 등록

## 5. 사용 흐름

### 관리자(교수자)
1. 오른쪽 위 **‘관리자’ 아이콘**으로 로그인 → **회원 현황 팝업**에서 가입 신청한 학습자 **승인**
2. **수업 관리**에서 15주차 구성과 수업 참여 링크 확인
3. **강의자료 추가** (주차·학습 방향·학습 수준 선택)
4. **YouTube URL 및 학습 구간 설정** (필요하면 원본 영상 자막 가리기 조정)
5. **원문 스크립트 확보** — YouTube 원문 자막 가져오기, 불가능하면 SRT 업로드 또는 원문 직접 입력
6. **자막 시간 동기화** — 영상을 보며 문장별 시작 시각 지정 (SRT·YouTube 자막처럼 타임코드가 있으면 생략)
7. **학습 콘텐츠 구성·검토** — 핵심 표현 · 어휘/문법 · 문화렌즈 · 퀴즈 초안 편집, 병음과 등장 시점 확인
8. **게시** — 공개 상태로 저장
9. **학습 현황 확인** — 학습자별 출석·주차 완료·영상 재생 정도·퀴즈
10. **Gmail 피드백** — 피드백 작성·검토 후 “Gmail로 보내기”

### 학습자
1. Google 계정으로 **로그인** → 회원정보 입력 → 관리자 승인 기다리기
2. 교수자가 공유한 참여 링크로 **수업 참여**
3. **주차·상황 학습**에서 강의 선택 (상황별 장면은 같은 화면의 두 번째 탭)
4. **영상과 자막·병음·학습 콘텐츠 학습** — 영상 위 자막과 학습 카드, 옆 패널의 스크립트·표현 학습
5. **문화렌즈 및 퀴즈** — 문화렌즈를 펼쳐 보고, 학습 구간을 마치면 복습 퀴즈
6. **내 대시보드**에서 학습 진행상황 확인

## 6. 배포 (GitHub → Railway)

GitHub 저장소를 Railway에 연결하면, main 브랜치에 커밋(푸시)할 때마다 자동으로 다시 배포됩니다.
`railway.json`에 빌드(`npm run build`)·실행(`npm start`) 명령과 상태 확인 주소(`/api/health`)가 들어 있어 따로 설정할 것이 없습니다.

단계별 안내(화면 클릭 순서, 오류가 났을 때 할 일)는 **[docs/배포-가이드.md](docs/배포-가이드.md)** 에 있습니다.

## 7. 데이터 저장과 한계

- 회원, 강의자료, 학습 기록, 피드백, 교수자 목록은 **서버의 JSON 파일 DB(`DATA_DIR/db.json`)** 에 저장됩니다. 다른 기기·브라우저에서도 같은 데이터를 봅니다.
- Railway에서는 **Volume을 `/data`에 연결하고 `DATA_DIR=/data`** 로 두어야 재배포해도 데이터가 남습니다. Volume이 없으면 배포할 때마다 초기화됩니다.
- 권한은 서버에서 확인합니다. 관리자만 회원 관리·강의자료 저장·전체 학습 기록을 볼 수 있고, 학습자는 본인 기록만, 승인 전에는 학습 기록을 저장할 수 없습니다.
- 2~15주차 대사는 실제 드라마 대사가 아니라 주제에 맞춰 **새로 쓴 학습용 초안**입니다. 영상을 정한 뒤 실제 대사로 바꿔 공개해 주세요.
- 기본 강의자료는 서버 DB가 처음 만들어질 때 한 번 들어갑니다. 이후 코드에서 기본 자료를 고쳐도 이미 저장된 강의자료는 바뀌지 않습니다. (관리자 화면에서 수정)
- `data/` 폴더는 저장소에 올라가지 않습니다. 내 컴퓨터에서 만든 강의자료를 커밋·배포에 넣으려면 **`npm run export-lessons`** 로 `src/content/savedLessons.ts`에 내보낸 뒤 커밋하세요. 처음 배포하는 서버는 이 내용으로 시작합니다. (회원·학습 기록·API 키는 내보내지 않습니다)
- YouTube 정책에 따라 자막 트랙이 확인되더라도 **자막 본문을 외부에서 직접 가져올 수 없는 영상**이 있습니다. 이 경우 SRT 업로드 또는 원문 직접 입력을 사용합니다.
- 학습 콘텐츠 초안은 HSK 등급에 맞춰 원문 문장을 고르는 **규칙 기반**입니다. 표현 뜻·문법·문화렌즈·퀴즈와 번역 자막은 **생성형 AI**로 채웁니다. 프롬프트를 외부 AI에 복사해 결과를 붙여 넣거나, 관리자 모드에서 본인 Anthropic API 키(또는 `ANTHROPIC_API_KEY`)를 연결해 바로 생성합니다. API로 생성하면 그 키의 계정에 사용량만큼 요금이 청구됩니다.
- 자동 병음은 규칙·사전 기반 변환이므로 다음자(多音字)는 확인이 필요할 수 있습니다.

## 8. 제출 및 보안 안내

- 제출 ZIP에는 **`.env`, `node_modules/`, `.git/`, `data/`** 를 포함하지 않습니다. (빌드 결과 `dist-app/`, `dist-server/`도 필요하지 않습니다.)
- 실행하려면 [3. 실행 방법](#3-실행-방법)에 따라 `npm install` 후, [4. 환경변수 설정](#4-환경변수-설정)의 형식으로 `.env`를 직접 만들어 주세요.
- Google Client Secret, OAuth access token 등 민감한 인증정보는 소스 코드와 저장소에 저장하지 않습니다. 로그인용 access token은 서버가 Google에 한 번 확인할 때만 쓰고, Gmail 발송용 access token은 브라우저 메모리에서만 사용하고 로그아웃 시 폐기합니다.
- 로그인 상태는 서버가 서명한 HttpOnly 쿠키로 유지됩니다.
